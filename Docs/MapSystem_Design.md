## 🎯 시스템 개요

### 용어 정의

```
Level (레벨): 진행 단계 (1, 2, 3...)
  - 각 레벨은 여러 스테이지로 구성
  - 각 레벨마다 조우 풀이 별도로 존재
  - 각 레벨의 마지막 스테이지는 보스 전투

Stage (스테이지): 레벨 내의 개별 구간
  - 전투/상점/휴식/이벤트 등 스테이지 타입
  - 스테이지 완료 시 1-3개의 다음 스테이지 선택지 제시
  - 마지막 스테이지는 레벨 보스

노드 ID 형식: "Lv.{레벨}-{스테이지}" (예: "1-3 전투", "2-1 상점")
```

### 핵심 콘셉트
**레벨-스테이지 진행 시스템**
- 각 레벨은 여러 스테이지로 구성
- 스테이지 완료 시 1-3개의 다음 스테이지 선택지 중 선택
- 각 레벨의 마지막은 보스 전투 (선택지 1개)
- 보스 클리어 시 다음 레벨로 진행

```
게임 루프:
[Level 1]
  Stage 1-1 (전투) → 선택지 → Stage 1-2 → ... → Stage 1-N (보스)
    ↓
[Level 2]
  Stage 2-1 → 선택지 → Stage 2-2 → ... → Stage 2-N (보스)
    ↓
  ... 반복 ...
    ↓
[마지막 레벨 보스 클리어] → 런 클리어!
```

### 디자인 목표
- 전략적 선택: 제시된 선택지 중 최선의 경로 선택
- 리스크/리워드: 엘리트 vs 일반 전투, 상점 vs 휴식
- 빠른 진행: 맵 화면 없이 선택 후 즉시 진입
- 리플레이성: 매 런마다 다른 선택지 트리
- 간결함: 단순하고 직관적인 흐름
- 레벨별 난이도: 같은 레벨 내 전투는 동일 조우 풀 사용

## 🗺️ 맵 구조

### 기본 구조 (MVP)

```
레벨-스테이지 트리 구조:

[Level 1]
Stage 1-1: ⚔️ 전투 (시작)
              ↓ (1-3개 선택지)
Stage 1-2: ⚔️ / 🛒 / ⚔️
              ↓ (각각 1-3개 선택지)
Stage 1-3: ⚔️ / 💤 / ⚔️
              ↓ (1개 - 보스로 수렴)
Stage 1-4: 👹 보스
              ↓ (1-3개 선택지 - 다음 레벨)

[Level 2]
Stage 2-1: ⚔️ / 🛒 / 💀
              ↓
         ... (레벨 내 스테이지 진행)
              ↓
Stage 2-N: 👹 보스
              ↓

[Level 3] ...

- 각 레벨은 2-4개의 일반 스테이지 + 1개의 보스로 구성
- 보스 전 마지막 스테이지 → 보스로 1개만 연결
- 보스 클리어 → 다음 레벨 첫 스테이지 선택지 (1-3개)
```

### 선택지 구조

```
구간              선택지 개수    설명
레벨 첫 스테이지   -            레벨 시작 (자동 또는 선택)
일반 스테이지      2-3개        각 스테이지마다 선택지 제공
보스 전           1개          보스로 필수 진행
보스 후           2-3개        다음 레벨 선택지
마지막 보스       -            런 클리어

레벨당 총 스테이지: 5개 고정 (일반 4개 + 보스 1개)
```

### 맵 생성 규칙

```
1. 레벨 생성 방식
   - 각 레벨: stagesPerLevel 개의 일반 스테이지 + 보스 1개 (모든 레벨 동일)
   - 기본값: 4개 일반 스테이지 + 보스 1개 = 총 5개

2. 스테이지 연결
   - 일반 스테이지: 2-3개의 다음 스테이지 선택지
   - 보스 스테이지: 선택지 1개만 (필수 진행)
   - 보스 클리어 후: 다음 레벨의 첫 스테이지로 이동

3. 스테이지 타입 결정
   - 확률 기반 랜덤 선택
   - 레벨별 출현 제한 (예: Elite는 Level 4+)

4. 선택지 개수
   - 일반 스테이지: 각 스테이지마다 2-3개 선택지 랜덤
   - 보스 스테이지: 1개 고정 (선택 불가)
```

## 📍 스테이지 타입

### 1. 전투 스테이지 (Combat) ⚔️

```
설명: 적과 전투
보상: 블록/유물/골드/회복 중 선택

일반 전투:
- 적 1-2체
- 표준 보상

출현 확률: 60%
```

### 2. 엘리트 스테이지 (Elite) 💀

```
설명: 강력한 적과 전투
보상: 희귀 블록/유물 획득 확률 증가

엘리트 전투:
- 강화된 적 1체 또는 다수 적
- 더 좋은 보상

출현 확률: 15%
출현 조건: Level 4 이후
```

### 3. 상점 스테이지 (Shop) 🛒

```
설명: 골드로 아이템 구매

판매 품목:
- 블록 추가 (10-30 골드)
- 유물 구매 (50-100 골드)
- HP 회복 (15 골드 = 10 HP)
- 블록 제거 (20 골드)

출현 확률: 10%
```

### 4. 휴식 스테이지 (Rest) 💤

```
설명: 휴식으로 회복

선택지:
1. 휴식: HP 30% 회복
2. 단련: 랜덤 블록 1개 강화 (공격/방어 +2)

출현 확률: 10%
```

### 5. 이벤트 스테이지 (Event) ❓

```
설명: 랜덤 이벤트 발생

예시 이벤트:
1. 신비한 상자
   - 열기: 랜덤 유물 획득 (50%)
   - 무시: 아무 일 없음

2. 수상한 상인
   - HP 10 지불 → 희귀 블록 획득
   - 거절 → 골드 +10

3. 버려진 제단
   - 기도: 랜덤 버프/디버프
   - 무시: 아무 일 없음

출현 확률: 5%
```

### 6. 보스 스테이지 (Boss) 👹

```
설명: 각 레벨의 마지막 보스

특징:
- 강력한 보스 1체
- 승리 시 해당 레벨 클리어
- 특별 보상 (희귀 유물 확정)
- 클리어 후 다음 레벨로 진행 (또는 마지막 레벨이면 런 클리어)

출현: 각 레벨의 마지막 스테이지 (고정)
```

### 스테이지 타입 분포 (MVP)

```
┌──────────┬──────┬─────────────┐
│ 스테이지 │ 확률 │ 레벨 제한   │
├──────────┼──────┼─────────────┤
│ 전투 ⚔️  │ 60%  │ 없음        │
│ 엘리트 💀│ 15%  │ Level 2+    │
│ 상점 🛒  │ 10%  │ 없음        │
│ 휴식 💤  │ 10%  │ 없음        │
│ 이벤트 ❓│ 5%   │ 없음        │
└──────────┴──────┴─────────────┘

보스 👹: 각 레벨 마지막 (자동 배치)
```

## ⚔️ 조우 풀 시스템

### 개념

각 레벨마다 **미리 정의된 전투 조우 풀**이 존재합니다. 플레이어가 해당 스테이지에 진입하면, 현재 레벨의 풀에서 **랜덤하게 하나의 조우**를 선택하여 전투가 시작됩니다.

```
조우(Encounter) = 적 배치 정보
- 4개의 고정 슬롯 (Slot 0-3)
- 각 슬롯은 비어있거나 적이 배치됨
- 슬롯 0: 가장 왼쪽/전방
- 슬롯 3: 가장 오른쪽/후방
```

### 데이터 구조

#### EncounterData (개별 조우)

```csharp
[CreateAssetMenu(fileName = "Encounter", menuName = "Data/Encounter")]
public class EncounterData : ScriptableObject
{
    public string encounterName;        // 조우 이름 (예: "슬라임 단독")

    // 4개의 고정 슬롯 (null 허용)
    public EnemyData enemySlot0;        // 슬롯 0 (전방 왼쪽)
    public EnemyData enemySlot1;        // 슬롯 1
    public EnemyData enemySlot2;        // 슬롯 2
    public EnemyData enemySlot3;        // 슬롯 3 (후방 오른쪽)
}
```

#### LevelEncounterConfig (레벨별 조우 풀)

```csharp
[System.Serializable]
public class LevelEncounterConfig
{
    public string levelLabel;           // 레벨 표시 (예: "Level 2")
    public List<EncounterData> combatEncounters;   // 일반 전투 조우 풀
    public List<EncounterData> eliteEncounters;    // 엘리트 전투 조우 풀
    public EncounterData bossEncounter;            // 이 레벨의 보스 조우
}
```

**중요**: 같은 레벨 내의 모든 전투/엘리트 스테이지는 동일한 조우 풀에서 랜덤 선택됩니다.

### 조우 예시

#### 예시 1: 슬라임 단독 (Level 1 - Normal)

```
encounterName: "슬라임 단독"

┌──────┬──────┬──────┬──────┐
│ 슬롯0 │ 슬롯1 │ 슬롯2 │ 슬롯3 │
├──────┼──────┼──────┼──────┤
│ 슬라임│  -   │  -   │  -   │
└──────┴──────┴──────┴──────┘

enemySlot0: Slime
enemySlot1: null
enemySlot2: null
enemySlot3: null
```

#### 예시 2: 고블린 2마리 (Level 2 - Normal)

```
encounterName: "고블린 듀오"

┌──────┬──────┬──────┬──────┐
│ 슬롯0 │ 슬롯1 │ 슬롯2 │ 슬롯3 │
├──────┼──────┼──────┼──────┤
│ 고블린│  -   │  -   │ 고블린│
└──────┴──────┴──────┴──────┘

enemySlot0: Goblin
enemySlot1: null
enemySlot2: null
enemySlot3: Goblin
```

#### 예시 3: 오크 보스 + 미니언 (Level 4 - Elite)

```
encounterName: "오크 리더와 부하들"

┌──────┬──────┬──────┬──────┐
│ 슬롯0 │ 슬롯1 │ 슬롯2 │ 슬롯3 │
├──────┼──────┼──────┼──────┤
│ 고블린│ 오크 │ 오크 │ 고블린│
└──────┴──────┴──────┴──────┘

enemySlot0: Goblin
enemySlot1: OrcWarrior
enemySlot2: OrcWarrior
enemySlot3: Goblin
```

### 조우 선택 로직

```
1. 플레이어가 스테이지 진입
2. 현재 levelIndex + StageType(Combat/Elite/Boss) 확인
3. 해당 레벨의 LevelEncounterConfig 로드
4. 타입에 따라:
   - Combat: combatEncounters에서 랜덤 선택
   - Elite: eliteEncounters에서 랜덤 선택
   - Boss: bossEncounter 사용
5. 선택된 EncounterData의 슬롯 정보로 적 생성
```

### 전체 조우 데이터

전체 레벨의 조우 풀 및 개별 조우 데이터는 별도 문서에 정의되어 있습니다.

## 🚶 진행 시스템

### 진행 흐름

```
1. 런 시작
   - Level 1, Stage 1 (일반 전투)로 자동 진입

2. 스테이지 완료
   - 전투: 승리 시 보상 선택
   - 상점/휴식/이벤트: 완료 즉시

3. 다음 스테이지 선택
   - 1-3개 선택지 카드 표시
   - 각 카드: 스테이지 타입, 레벨-스테이지 번호
   - 보스 직전: 보스 1개만 (필수 선택)

4. 선택 후 즉시 진입
   - 맵 화면 없이 바로 스테이지 시작
   - 전투/상점/휴식/이벤트/보스

5. 레벨 보스 클리어
   - 다음 레벨의 첫 스테이지 선택지 표시 (1-3개)
   - 마지막 레벨 보스 클리어 시 런 클리어

6. 반복
   - 마지막 레벨 보스 클리어까지 반복
```

### 보상 선택 (MVP)

```
전투 승리 시:

┌─────────────────────────────────┐
│       전투 승리!                │
├─────────────────────────────────┤
│                                 │
│      [보상 받기]                │
│                                 │
└─────────────────────────────────┘

MVP: 간단한 버튼만
Post-MVP: 블록/유물/회복 등 선택
```

### 스테이지 선택 UI (MVP)

```
스테이지 완료 후:

┌─────────────────────────────────────────┐
│     다음 스테이지를 선택하세요          │
├─────────────────────────────────────────┤
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  │
│  │ ⚔️ 전투 │  │ 🛒 상점 │  │ ⚔️ 전투 │  │
│  │         │  │         │  │         │  │
│  │   1-2   │  │   1-2   │  │   1-2   │  │
│  └─────────┘  └─────────┘  └─────────┘  │
└─────────────────────────────────────────┘

- 1-3개 카드 (가변)
- 클릭하면 즉시 해당 스테이지 진입
- 보스 직전: 보스 1개만 표시
- 레벨 보스 클리어 후: 다음 레벨 첫 스테이지 선택지
```

### 런 종료 조건

```
승리:
- 마지막 레벨의 보스 스테이지 클리어

패배:
- 플레이어 HP 0

런 종료 시:
- 런 통계 표시 (처치 수, 획득 골드, 클리어 레벨)
- 메인 메뉴로 이동
```

별도 버튼으로 진행 내역 확인 가능:
- 완료한 스테이지 목록
- 선택한 경로 시각화
- 획득한 보상 내역
```

## 📦 MVP 범위

### Phase 1: 기본 선택 시스템 (1일)

```
✅ 구현:
- 트리 구조 랜덤 맵 생성 (7단계)
- 6가지 스테이지 타입 (전투/엘리트/상점/휴식/이벤트/보스)
- 스테이지 선택 카드 UI (1-3개 선택지)
- 보상 플레이스홀더 ("보상 받기" 버튼)
- 전투 → 선택 → 전투 플로우

❌ 제외:
- 맵 화면 (향후 히스토리용으로만)
- 실제 보상 선택 시스템
- 상점/휴식/이벤트 실제 콘텐츠
```

### Phase 2: 완전한 통합 (Post-MVP)

```
✅ 구현:
- 실제 보상 선택 시스템 (블록/유물/회복)
- 상점 시스템 (구매)
- 휴식 시스템 (회복/강화)
- 이벤트 시스템 (여러 이벤트)
- 진행 내역 확인 UI
- 런 통계 및 승리/패배 화면

❌ 제외:
- 복잡한 이벤트 (10개+)
- 여러 스테이지/테마
```

## 🎮 플레이 예시

### 런 진행 시나리오

```
1. 런 시작
   - 트리 맵 생성
   - Level 1 (일반 전투)로 자동 진입

2. Level 1: ⚔️ 전투
   - 슬라임과 전투
   - 승리 → 보상 받기 (MVP: 버튼만)
   - 선택지 표시: [⚔️ 전투 | 🛒 상점 | ⚔️ 전투]

3. 상점 선택 🛒
   - 상점 진입 (MVP: 자동 완료)
   - 선택지 표시: [⚔️ 전투 | 💤 휴식]

4. 휴식 선택 💤
   - 휴식 완료 (MVP: 자동 완료)
   - 선택지 표시: [⚔️ 전투 | 💀 엘리트 | ⚔️ 전투]

5. 엘리트 선택 💀
   - 강화된 오크와 전투
   - 승리 → 보상 받기
   - 선택지 표시: [⚔️ 전투 | ⚔️ 전투]

6. 전투 선택 ⚔️
   - 적 2체와 전투
   - 승리 → 보상 받기
   - 선택지 표시: [👹 보스] (1개만)

7. 보스 진입 👹
   - 오크 보스와 전투
   - 승리 → 런 클리어!
   - 승리 화면 표시
```

## 💡 밸런싱 고려사항

### 난이도 곡선

```
Level 1-2: 쉬움
- 슬라임, 고블린 단일
- 기본 블록으로 클리어 가능

Level 3-4: 보통
- 다수 적 등장
- 상점/휴식으로 강화 필요

Level 5-6: 어려움
- 엘리트 등장
- 전략적 블록 운용 필수

Level 7: 보스
- 보스 전용 패턴
- 충분한 준비 필요
```

### 보상 밸런스

```
전투 승리 시:
- 블록: 50% 확률
- 유물: 30% 확률
- 회복: 20% 확률

엘리트 승리 시:
- 희귀 블록: 40% 확률
- 희귀 유물: 50% 확률
- 회복+골드: 10% 확률

## 🔮 향후 확장

### 경로 연결 방식 (Slay the Spire 스타일)

```
현재 (MVP): 층별 독립 선택
- 각 층에서 어떤 스테이지든 선택 가능
- 구현 단순

확장: 경로 연결 방식
- 스테이지 간 경로가 그물처럼 연결
- 이전 스테이지 선택이 다음 선택지 제한
- 더 전략적, 구현 복잡
```

### 월드 시스템

```
World 1: 숲 (7레벨)
World 2: 동굴 (7레벨)
World 3: 성 (7레벨)
→ 각 월드마다 다른 적, 보상, 테마
```

### 난이도 옵션

```
- Normal: 기본
- Hard: 적 강화, 보상 증가
- Ascension: 무한 난이도 시스템
```
