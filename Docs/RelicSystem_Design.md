## 📖 개요

### 목적
런 동안 플레이어를 **영구적으로 강화**하는 패시브 아이템

### 핵심 원칙
1. **명확한 효과**: 유물 효과가 즉시 이해됨
2. **빌드 다양성**: 유물 조합에 따라 다른 전략
3. **획득의 기쁨**: 유물 획득이 보람 있음

### 기본 규칙
- 유물은 **중복 획득 불가** (런 당 1개씩만)
- 유물 효과는 **즉시 적용** (획득 시점부터)
- 유물은 **런 종료 시 초기화** (로그라이크)

## 🏅 유물 등급

### 일반 (Common)
```
획득 경로: 일반/엘리트 전투 보상, 상점
효과 강도: 기본적인 스탯 증가

예시: 공격 +2, 방어 +5, 전투 시작 시 HP +5
```

### 보스 (Boss)
```
획득 경로: 보스 처치 시 확정 획득
효과 강도: 강력한 효과, 게임 체인저

예시: 골드 효과 2배, 위기 시 공격력 대폭 증가
```

## ⏰ 효과 발동 시점

### 상시 (Passive)
```
설명: 항상 적용
예시: "모든 공격 +2"
```

### 전투 시작 (OnBattleStart)
```
설명: 전투 시작 시 1회 발동
예시: "전투 시작 시 HP +5 회복"
```

### 턴 시작 (OnTurnStart)
```
설명: 매 턴 시작 시 발동
예시: "턴 시작 시 방어 +3"
```

### 조건부 (Conditional)
```
설명: 특정 조건 충족 시 발동
예시: "HP 30% 이하일 때 공격 +5"
```

### 블록 매치 시 (OnBlockMatch)
```
설명: 특정 블록 매치 시 발동
예시: "빨간 블록 매치 시 추가 데미지 +1"
```

## 🗝️ MVP 유물 목록

> MVP에서는 **전투 시작 시** 효과 유물을 우선 구현 (기존 상태 효과 시스템 활용)

### 일반 유물 (Phase 1 - 전투 시작 시 효과)

#### 1. 전사의 문장 (Warrior's Emblem)
```
아이콘: ⚔️
효과: 전투 시작 시 STR(2) 획득
발동: 전투 시작
상태 효과: STR +2

설명: 전투 시작 시 공격력이 2 증가합니다.
```

#### 2. 철벽의 갑옷 (Iron Armor)
```
아이콘: 🛡️
효과: 전투 시작 시 PLATED(5) 획득
발동: 전투 시작
상태 효과: PLATED +5

설명: 전투 시작 시 받는 데미지가 5 감소합니다.
```

#### 3. 회복의 부적 (Amulet of Healing)
```
아이콘: 🧿
효과: 전투 시작 시 HP +5 회복
발동: 전투 시작

설명: 전투 시작 시 HP를 5 회복합니다.
```

### 보스 유물 (Phase 1 - 전투 시작 시 효과)

#### 4. 독사의 반지 (Viper's Ring)
```
아이콘: 🐍
효과: 전투 시작 시 모든 적에게 POISON(3) 적용
발동: 전투 시작
상태 효과: POISON +3 (적에게)

설명: 전투 시작 시 모든 적이 독에 걸립니다.
```

#### 5. 재생의 심장 (Heart of Regeneration)
```
아이콘: 💚
효과: 전투 시작 시 REGEN(3) 획득
발동: 전투 시작
상태 효과: REGEN +3

설명: 전투 시작 시 3턴간 HP가 회복됩니다.
```

> 상시/조건부/블록 매치 효과는 추가 로직 필요

구현 복잡도: 중 (데미지 계산 보정 필요)

```
아이콘: 📿

발동: 상시
구현 복잡도: 중 (스탯 변경 필요)
```

#### 행운의 동전 (Lucky Coin)
```
아이콘: 🪙

발동: 블록 매치 시
구현 복잡도: 중 (골드 계산 로직 수정)

#### 불굴의 의지 (Indomitable Will)
```
아이콘: 🔥

## 📦 MVP 범위

### MVP 포함
```
✅ 포함:
- 전투 시작 시 유물 5종 (일반 3, 보스 2)
  - 전사의 문장: STR +2
  - 철벽의 갑옷: PLATED +5
  - 회복의 부적: HP +5
  - 독사의 반지: 적에게 POISON +3
  - 재생의 심장: REGEN +3
- 유물 획득 및 효과 적용
- 보유 유물 UI 표시
- 보상에서 유물 선택
- 기존 상태 효과 시스템 활용

❌ 제외 (Post-MVP):
- 상시/조건부/블록 매치 효과 유물
- 유물 시너지 효과
- 유물 업그레이드
```

## 🔧 구현 우선순위

### 핵심 원칙
```
기존 상태 효과 시스템(StatusEffects.md)을 최대한 활용하여 구현
→ STR, PLATED, REGEN, POISON, WEAK, VULNERABLE 등
```

### Phase 1: 전투 시작 시 효과 (우선 구현)
```
구현 방식: 전투 시작 시 플레이어에게 버프 또는 적에게 디버프 적용

예시 유물:
- 전사의 문장: 전투 시작 시 STR(2) 획득
- 독사의 반지: 전투 시작 시 모든 적에게 POISON(3) 적용
- 철벽의 갑옷: 전투 시작 시 PLATED(5) 획득
- 재생의 부적: 전투 시작 시 REGEN(3) 획득

장점:
- 기존 상태 효과 시스템 그대로 사용
- 전투 시작 시 ApplyStatusEffect() 호출만 하면 됨
- 구현 복잡도 낮음
```

### Phase 2: 기타 효과 (추후 구현)
```
상시 (Passive):
- 모든 공격 +N → 별도 로직 필요 (데미지 계산 시 보정)
- 최대 방어력 +N → Player 스탯 변경

조건부 (Conditional):
- HP 50% 이하일 때 STR(+N) → 조건 체크 로직 필요

블록 매치 시 (OnBlockMatch):
- 빨간 블록 매치 시 추가 효과 → 블록 매치 이벤트 연동
- 골드 블록 2배 → 골드 계산 로직 수정

턴 시작 시 (OnTurnStart):
- 매 턴 방어 +N → 턴 시작 이벤트 연동
```

### MVP 유물 구현 매핑
```
1. 공격의 반지 → Phase 2 (상시, 데미지 보정 필요)
2. 방어의 목걸이 → Phase 2 (상시, 스탯 변경 필요)
3. 회복의 부적 → Phase 1 (전투 시작 시 HP 회복)
4. 행운의 동전 → Phase 2 (블록 매치 시, 골드 계산 수정)
5. 불굴의 의지 → Phase 2 (조건부, HP 체크 로직)
```

### 추천 구현 순서
```
Step 1: 회복의 부적 (전투 시작 시 HP +5)
  → 가장 단순, 전투 시작 이벤트만 필요

Step 2: 전투 시작 버프 유물 추가 (STR, PLATED, REGEN 등)
  → 기존 상태 효과 시스템 활용

Step 3: 상시 효과 유물 (공격의 반지, 방어의 목걸이)
  → 데미지/스탯 계산 로직 수정

Step 4: 조건부/블록 매치 유물
  → 이벤트 시스템 확장 필요
```

## 🔮 Post-MVP 확장

### Phase 2: 유물 확장
```
추가 일반 유물:
- 연쇄의 반지: 블록 연쇄 보너스 +10%
- 흡혈의 검: 공격 데미지의 10% HP 회복
- 황금 주머니: 전투 종료 시 골드 +5
- 수호의 방패: 턴 시작 시 방어 +2

추가 보스 유물:
- 시간의 모래: 턴당 블록 매치 2회 가능
- 무한의 심장: 최대 HP +30
```

### Phase 3: 유물 시너지
```
특정 유물 조합 시 추가 효과:
- 공격 세트 (3개): 추가 공격 +3
- 방어 세트 (3개): 추가 방어 +5
```
