## 📖 개요

### 목적
전투 중 소진된 HP를 회복하고, 전략적 성장 기회 제공

### 핵심 원칙
1. **안전한 선택지**: 위험 없이 HP 회복 가능
2. **빠른 진행**: 복잡한 선택 없이 즉시 회복 후 진행

### 발동 시점
- 맵에서 휴식 지점(Rest) 스테이지 선택 시

## 🛌 MVP 기능

### 1. HP 회복

```
효과: HP 일정량 회복
회복량: 30 HP (고정)
비용: 무료
제한: 최대 HP 초과 불가

예시:
현재 HP: 45/100
회복 후: 75/100

현재 HP: 85/100
회복 후: 100/100 (최대치)
```

### 2. 흐름

```
휴식 지점 진입
    ↓
[UI 표시] - "휴식하기" 버튼
    ↓
[HP 회복] - 즉시 30 HP 회복
    ↓
[피드백 표시] - "+30 HP" 애니메이션
    ↓
맵으로 복귀
```

## 🔮 Post-MVP 확장

### Phase 2: 선택지 추가

```
Option A: 휴식 (무료)
- HP 30 회복

Option B: 블록 강화 (골드 소모)
- 특정 블록 효과 증가
- 비용: 50~100 골드
- 예: 검 블록 공격력 +5 → +7

Option C: 블록 제거 (골드 소모)
- BlockPool에서 특정 블록 제거
- 비용: 75 골드
- 예: 쓰레기 블록 제거
```

### Phase 3: 고급 기능

```
- 최대 HP 증가 (골드 소모)
- 블록 출현 확률 조절
- 특수 이벤트 (랜덤)
```

## 📦 구현 사항

### MVP 클래스 구조

```csharp
// RestManager.cs
public class RestManager : MonoBehaviour
{
    // 회복량
    private const int REST_HEAL_AMOUNT = 30;

    // 휴식 완료 이벤트
    public UnityEvent OnRestCompleted;

    // HP 회복
    public void Rest(Player player)
    {
        player.Heal(REST_HEAL_AMOUNT);
        OnRestCompleted?.Invoke();
    }

    // 건너뛰기
    public void Skip()
    {
        OnRestCompleted?.Invoke();
    }
}
```

### 통합 포인트

1. **MapManager**: `StageType.Rest` 진입 처리
2. **RestUI**: 휴식 화면 표시
3. **Player**: HP 회복 적용
