## 📖 개요

### 목적
전투 승리 후 플레이어에게 **선택권**을 부여하여 전략적 성장 경험 제공

### 핵심 원칙
1. **의미 있는 선택**: 모든 보상이 상황에 따라 가치가 다름
2. **명확한 정보**: 보상 효과를 즉시 이해할 수 있음
3. **빠른 진행**: 선택 후 즉시 다음 단계로

### 발동 시점
- 일반 전투 승리
- 엘리트 전투 승리
- 보스 전투 승리

## 🎁 보상 타입

### 1. 골드 (Gold)

```
아이콘: 💰
효과: 골드 획득

일반 전투: 10~20 골드
엘리트 전투: 25~40 골드
보스 전투: 50~75 골드

용도:
- 상점에서 블록/유물 구매
- 휴식 시 추가 회복
```

### 2. 유물 (Relic)

```
아이콘: 🔮
효과: 패시브 능력 획득

출현 확률:
- 일반 전투: 15%
- 엘리트 전투: 40%
- 보스 전투: 100% (확정)

유물 등급:
- 일반: 기본 효과
- 희귀: 강화된 효과
- 전설: 게임 체인저 (보스 보상만)

참고: RelicSystem_Design.md (별도 문서)
```

### 3. HP 회복 (Heal)

```
아이콘: ❤️
효과: 현재 HP 회복

회복량:
- 일반 전투: 15~25 HP
- 엘리트 전투: 25~35 HP
- 보스 전투: 전체 회복

제한: 최대 HP 초과 불가
```

### 4. 최대 HP 증가 (Max HP Up)

```
아이콘: 💖
효과: 최대 HP 영구 증가

증가량:
- 일반 전투: +5 HP
- 엘리트 전투: +8 HP
- 보스 전투: +10 HP

출현 확률: 10% (희귀 보상)
```

### 5. 블록 수정 (Block Modify) - Post-MVP

> ⚠️ **Post-MVP**: 기획만 정리, 추후 구현

```
아이콘: 🔧
효과: BlockPool 변경
```

#### 방식 A: 블록 추가 (Add)
```
효과: BlockPool에 새 블록 종류 추가
예시: "도끼 블록이 보드에 출현합니다"

장점: 덱빌딩 느낌, 전략적 선택
단점: 추가 후 실제 출현까지 운 필요

구현 고려사항:
- 추가 시 초기 가중치를 높게 설정
- 또는 추가 즉시 보드에 1개 배치 (보너스)
```

#### 방식 B: 블록 강화 (Upgrade)
```
효과: 기존 블록의 효과 수치 증가
예시: "검 공격력 +5 → +7"

장점: 즉각적인 파워업 체감, 단순 명확
단점: 해당 블록이 나와야 효과 체감
```

#### 방식 C: 블록 제거 (Remove)
```
효과: BlockPool에서 블록 제거
예시: "쓰레기 블록 제거"

장점: 덱 압축, 원하는 블록 확률 증가
단점: 제거할 블록이 없으면 무의미
```

#### 방식 D: 출현 확률 변경 (Weight)
```
효과: 특정 블록의 출현 가중치 증가/감소
예시: "검 블록 출현 확률 +20%"

장점: 기존 블록을 더 자주/드물게 조절
단점: 수치가 직관적이지 않을 수 있음

구현 고려사항:
- UI에서 "자주 나옴" / "가끔 나옴" 등 텍스트로 표현
- 또는 별 개수로 빈도 표시 (★★★)
```

#### 구현 우선순위
```
1순위: 블록 강화 - 가장 직관적
2순위: 블록 추가 - 덱빌딩 핵심
3순위: 블록 제거 - 고급 전략
4순위: 출현 확률 변경 - 세밀한 조절
```

## 🔄 보상 선택 흐름

### 기본 흐름

```
전투 승리
    ↓
[보상 생성] - 3개 보상 랜덤 생성
    ↓
[보상 UI 표시] - 3개 카드 형태
    ↓
[플레이어 선택] - 1개 선택 또는 건너뛰기
    ↓
[보상 적용] - 즉시 효과 반영
    ↓
다음 단계 (맵 이동)
```

### 선택 규칙

```
필수 선택: X (건너뛰기 가능)
다중 선택: X (1개만)
되돌리기: X (선택 확정)
시간 제한: X (무제한)
```

## 🎲 보상 생성 규칙

### 기본 확률 (일반 전투)

| 보상 타입 | 확률 |
|----------|------|
| 골드 | 30% |
| HP 회복 | 25% |
| 블록 추가 | 25% |
| 블록 강화 | 10% |
| 최대 HP 증가 | 5% |
| 유물 | 5% |

### 엘리트 전투 보정

```
유물 확률: 5% → 30%
블록 강화 확률: 10% → 20%
골드 양: 1.5배
```

### 보스 전투 보정

```
유물: 100% (1개 확정)
나머지 2개: 일반 규칙
골드 양: 2배
```

### 중복 방지

```
같은 타입 최대 1개까지
예: 골드 + 골드 + HP 회복 (O)
예: 골드 + 골드 + 골드 (X)

유물은 항상 1개까지
```

### 상황 보정

```
HP 30% 이하:
  → HP 회복 출현 확률 +20%

골드 10 이하:
  → 골드 출현 확률 +15%

BlockPool이 작을 때 (5개 이하):
  → 블록 추가 출현 확률 +15%
```

## 📦 MVP 범위

### MVP 보상

```
✅ 포함:
- 골드 보상 (15~20)
- HP 회복 보상 (15~25)
- 최대 HP 증가 보상 (+5)
- 건너뛰기 기능

❌ 제외 (Post-MVP):
- 유물 보상 → 유물 시스템 완성 후
- 블록 수정 (추가/강화/제거/확률) → 기획 검토 후
- 상황 보정 로직
- 등급별 연출
```
